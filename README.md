# Homebrew tap for Cappy

Install [Cappy](https://github.com/joetam/cappy):

```sh
brew install --cask joetam/tap/cappy
```

Current builds are not yet notarized. If macOS blocks the first launch, try to open Cappy once, click **Done**, then go to **System Settings → Privacy & Security**. Scroll to **Security**, click **Open Anyway** next to Cappy, and confirm **Open**.
